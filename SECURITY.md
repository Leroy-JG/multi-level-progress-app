# Sécurité

Alam fonctionne hors ligne, sans compte ni serveur : les données restent sur l'appareil.

- Signaler une vulnérabilité : ouvrir un signalement privé (Security → Report a vulnerability) sur GitHub.
- Sauvegarde : Réglages → Exporter une sauvegarde (JSON). Le fichier n'est pas chiffré : le garder en lieu sûr.
- Installer l'APK uniquement depuis les « Artifacts » / releases de ce dépôt.
