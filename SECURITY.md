# Sécurité

Alam fonctionne hors ligne, sans compte ni serveur : les données restent sur l'appareil (détails et garanties vérifiables dans [PRIVACY.md](PRIVACY.md)).

- Signaler une vulnérabilité : ouvrir un signalement privé (Security → Report a vulnerability) sur GitHub.
- Sauvegarde : Réglages → Exporter une sauvegarde (JSON). Le fichier n'est pas chiffré : le garder en lieu sûr. Personne d'autre n'a de copie des données : sans sauvegarde, elles sont perdues avec l'appareil.
- Installer l'APK uniquement depuis les « Artifacts » / releases de ce dépôt.
- Sauvegardes automatiques (facultatives) : copies gardées sur l'appareil, dans le même espace privé que les données, non chiffrées ; supprimées par « Effacer toutes mes données ». Elles ne remplacent pas un fichier exporté (elles disparaissent avec l'appareil ou une désinstallation).
